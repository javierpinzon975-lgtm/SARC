# Complementos del proyecto SARC

Esta sección reúne desarrollos complementarios, pruebas de concepto y exploraciones tecnológicas elaboradas durante el proceso de formación del proyecto SARC (Sistema de Agendamiento, Recordatorio y Cancelación de Citas Médicas).

Los componentes se mantienen organizados de forma independiente respecto a la aplicación principal. Su objetivo es documentar experimentaciones, validar tecnologías emergentes y explorar posibles ampliaciones del sistema.

## Componentes

### SARC Blockchain POC
Prueba de concepto académica de trazabilidad e integridad de eventos de citas mediante una cadena de bloques simulada con SHA-256.

**Estado:** Desarrollado y probado.

Ruta: `SARC_Blockchain_POC/`

### Aplicación móvil
Espacio destinado al desarrollo de una aplicación móvil complementaria para el proyecto SARC.

**Estado:** Pendiente de desarrollo.

Ruta: `Aplicación_Móvil/`

## Consideraciones

Los componentes de esta carpeta son desarrollos independientes y no necesariamente forman parte de la implementación funcional de la aplicación principal. Cada uno cuenta con su propia documentación, recursos y condiciones de ejecución.
